# Video Saver website

Static GitHub Pages site for the Video Saver Chrome extension.

## Before commercial launch

The public pages intentionally do not display the operator's personal name,
address, or email. Lemon Squeezy can still receive those details privately for
identity and payout verification. Obtain appropriate UK legal advice and add
any required trader identity, geographic address, and electronic contact details
before using the site to sell or promote a paid online service.

Run `node validate-site.cjs` before publishing.

## Publish with GitHub Pages

1. Create a public GitHub repository named `video-saver-site`.
2. Commit the contents of this directory at the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Confirm `https://YOUR-GITHUB-NAME.github.io/video-saver-site/` loads in a signed-out browser.

After Chrome Web Store approval, replace the “Coming soon” element on the home
page with the live listing link.
